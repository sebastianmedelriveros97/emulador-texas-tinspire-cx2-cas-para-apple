Salida de print() y errores
Variables del documento (var.store / var.recall). Cambiarlas dispara on.varChange.

Cómo usarlo

  1. Abrir un .lua o un .tns generado con Luna o con este emulador, o elegir un ejemplo.
  2. Editar en Código y pulsar ▶ Ejecutar.
  3. Interactuar con el teclado táctil, tocando la pantalla, o con un teclado físico.
  4. ⬇ .tns genera el documento listo para enviar a la calculadora con TI-Nspire Link / TI Connect.

Teclado físico

Flechas, Enter, Esc, Tab (⇧Tab), Retroceso, Supr. ⌘M abre el menú (toolpalette). ⌘↵ ejecuta el código.

Qué se emula

La API Lua de la calculadora: on.* (paint, charIn, arrowKey, enterKey, mouseDown, timer…), gc (texto, líneas, rectángulos, arcos, polígonos, imágenes, recortes), platform, timer, var, toolpalette, image, D2Editor, cursor, class() y math.eval (numérico).

Diferencias con la calculadora

  • No incluye el sistema operativo de TI ni su CAS: math.eval evalúa expresiones numéricas, sin resultados simbólicos.
  • Las fuentes son del sistema, así que el ancho del texto puede variar unos píxeles.
  • La velocidad del iPad es muy superior: prueba siempre el rendimiento en la calculadora.
  • Los enteros de Lua son de 32 bits en el emulador; en la calculadora son números reales de 64 bits.
